# Visual Asset Hub 操作說明

> 把一張照片拆成多個去背素材，自動加上類別與情境標籤，用中文找素材，再排進商品主圖、IG 貼文、Banner 匯出。

開啟方式：伺服器啟動後（見 [SETUP_NEW_PC.md](SETUP_NEW_PC.md)），用瀏覽器開 **http://localhost:8000**。
上方導覽列有四個頁面：**上傳 → 素材庫 → 搜尋 → 設計**，大致就是一般的工作順序。

---

## 1. 上傳照片

1. 進入「**上傳**」，把照片拖進虛線框（或點一下選檔案，可一次多張）。
2. 每張照片會顯示狀態：
   - **處理中**：背景正在分割物件、判斷類別與情境；排隊時會顯示「第 N 位」。每張約 3–4 秒；伺服器剛啟動後的第一張要再多約 10 秒（載入模型）。
   - **完成**：可以點「**確認候選**」。
   - **失敗**：滑鼠移到標籤上可看原因。
3. 同一張照片重複上傳不會重算，會直接沿用已存在的那張。
4. 超過 4096 px 的大照片會自動縮小後再處理。

> 刪除照片會連同它的所有素材一起刪除。

## 2. 確認候選（把物件變成素材）

系統會從照片中找出很多「候選物件」，由你勾選要留下哪些。

- **左邊照片**：滑鼠移到物件上會亮起**橘色**；點一下即**選取（藍色）**；已經變成素材的顯示**綠色**。
- **右邊清單**：
  - 有 YOLO 類別（例如「YOLO cup」）的排在前面，其餘依「**像物件**」程度排序。
  - 看起來像背景或碎片的（像物件 < 40%）收合在「**顯示其他 N 個**」裡，需要時再展開。
- 上方按鈕：
  - **全選有類別的**：一次選起系統有把握的物件。
  - **確認 N 個為素材**：開始去背與標註，每個約 1 秒，會顯示進度。
  - **捨棄**：標記不要的候選（之後仍可再選回來）。
- 完成後會出現「已建立 N 個素材」，可點「到素材庫」查看。

小技巧：大物件與它的局部（例如「整個杯子」與「杯套」）可能各是一個候選，選你需要的那個即可。

## 3. 素材庫

- 用上方的 **類別 / 標籤** 下拉選單篩選；從確認頁點過來時會自動篩選「這張照片的素材」。
- 點素材卡片，右側開啟詳情：
  - **下載透明 PNG**（原尺寸）。
  - **類別**：系統判錯時可直接改（例如把被認成「安全帽」的咖波改成「公仔」）。改過的類別會標示「手動設定」，也會用來推論情境。
  - **情境 / 屬性標籤**：按 × 移除、從「新增標籤…」加入；手動加的以虛線外框顯示。重新標註時會保留你的修改。
  - **來源照片**：顯示素材在原照片的位置，點連結回到確認頁。
  - **刪除素材**：素材刪掉後，它的候選會回到「待確認」。

## 4. 搜尋

- 用中文描述想要的東西，例如：
  「和在咖啡廳工作有關的物件」、「適合下班小酌的東西」、「可愛的公仔」、「藍色的東西」、「騎車要用的」。
- 結果上方會顯示系統的理解，例如「理解為：情境 小酌」。每張結果附**分數**與**命中原因**（類別、情境、屬性、語意相似度）。
- 預設不顯示「人物」（照片中的手等）；需要時勾選「**包含人物（手）**」。
- 點結果可開啟與素材庫相同的詳情面板（改類別、標籤、下載）。

> 詞彙表裡的說法（同義詞）最準，例如「保溫杯」「帆布袋」「下午茶」。完全沒對到詞彙時只靠語意相似度，結果會比較發散。

## 5. 設計（畫布與匯出）

1. 進入「**設計**」，選一種尺寸建立：**商品主圖 800×800**、**IG 貼文 1080×1350**、**Banner 1640×856**。
2. 編輯器分三欄：
   - **左：素材** —— 搜尋或用類別篩選，**點一下**加到畫布中央，或**拖曳**到想放的位置。
   - **中：畫布** —— 拖曳移動；拉角落等比縮放（文字是拉左右兩側調整寬度）；拉上方延伸出來的小方塊旋轉；靠近中線會自動對齊（橘色虛線）。
   - **右：屬性** —— 沒選東西時是背景與匯出紀錄；選了圖層時可調整該圖層。
3. 常用操作：
   - **＋ 文字**：新增文字；在右側改內容、字型（微軟正黑體 / 新細明體 / Arial）、字級、顏色、粗體、對齊、行距。
   - **套用版型**：自動排好位置。商品主圖：「置中商品」「商品＋底部文字」；IG：「大圖＋標題」「雙素材」；Banner：「左文右圖」「左圖右文」。版型會排前 1–2 個素材與文字，其他圖層保持原位。
   - **素材圖層**：水平翻轉、不透明度、陰影、**置中並填滿**、圖層順序（置頂 / 上移 / 下移 / 置底）、複製、刪除。
   - **背景**：純色、雙色漸層（可選方向）、透明。
   - **換尺寸**：直接改上方的尺寸選單，所有圖層會等比例換算。
4. **匯出**：選 PNG 或 JPEG，按「**匯出 寬×高**」。檔案會下載到電腦，尺寸與預設完全一致；同時存一份在伺服器，右側「匯出紀錄」可再次下載。
   - PNG 會保留透明背景；JPEG 不支援透明，透明處會填白。
5. 設計會**自動儲存**（工具列顯示「已儲存 時間」），之後可在「設計」頁再打開修改。

快捷鍵（游標不在輸入框時）：

| 按鍵 | 作用 |
|---|---|
| Delete / Backspace | 刪除選取的圖層 |
| 方向鍵（加 Shift = 10 px） | 微調位置 |
| Ctrl+Z / Ctrl+Y（或 Ctrl+Shift+Z） | 復原 / 重做（最多 50 步） |
| Ctrl+D | 複製圖層 |
| Esc | 取消選取 |

> 如果設計用到的素材後來被刪除，畫布上會以**紅色虛線框**標示「素材已刪除」，刪掉該圖層或換成其他素材即可。

## 範例流程：做一張「咖啡廳工作」IG 貼文

1. **上傳**一張有筆電和咖啡杯的照片 → 等狀態變「完成」→「確認候選」。
2. 按「全選有類別的」，取消不要的，按「確認」→ 得到筆電、咖啡杯素材（系統會自動加上「遠距工作」「咖啡廳」情境）。
3. **設計** → 新增「IG 貼文」→ 左側搜尋「咖啡廳工作」→ 點筆電、咖啡杯加入。
4. 「套用版型」選「**雙素材**」→ 點標題改成「週五咖啡廳辦公日」→ 背景改成漸層。
5. 選 PNG →「匯出 1080×1350」。

## 常見問題

| 狀況 | 處理 |
|---|---|
| 照片一直「處理中」 | 檢查啟動伺服器的命令列視窗是否有錯誤；伺服器重開後會自動接續處理 |
| 物件類別判錯 | 在素材庫詳情直接改類別（之後的情境推論也會跟著修正） |
| 候選太多、很多碎片 | 低分的已自動收合；只勾需要的即可，其餘不用處理 |
| 搜尋找不到 | 換成較具體的名稱（例如「馬克杯」→「咖啡杯」），或到素材庫用類別篩選 |
| 匯出的字型和別台電腦不同 | 畫布使用系統字型，沒有「微軟正黑體」的電腦會用替代字型 |
